## Design specificity

Half authored, half template. Inner layer (WorkflowStrip, AutoAdvancePanel, ContextGauge, comments to agent session, composer banner) is product-specific. Outer layer (tagline, Tasks | Drafts | New task, aside counters, Name/Step/Sessions/Created/Updated table) is a generic tracker. The workflow strip is inert and duplicated by MinimapPanel.

## Priority issues

- P0 Red means "waiting for you": statusMeta maps ready_for_input to danger + AlertCircle; ROW_SHADE_CLASS.danger tints rows; red dots in TaskTable/TaskBoard; RpiThreadList red icons; failed shares the tone. Fix: attention tone, "Needs you", distinct icon, danger reserved for failed/lost, count chip instead of dot.
- P0 No "what needs me" surface: aside shows counts + duplicate CTA + view toggle. Fix: attention queue of ready_for_input | needs_approval | failed sessions grouped by task, one click to thread, empty state "Nothing needs you."
- P1 Chrome duplication and "LIST LIST": Create task x3, List/Board x2, static span beside state-labelled button. Fix: delete the aside, one CTA, one segmented control; panelLayoutMode goes away.
- P1 Seven detail tabs + inert WorkflowStrip on each; tabs clip silently at 500px and on phone. Fix: Sessions, Artifacts, Settings; strip becomes the real minimap with counts/status/click-to-filter; delete MinimapPanel; Scratch in a drawer; Tips collapsible in Sessions.
- P1 Comment gutter is opacity-0 group-hover with no focus-visible: invisible on touch and to keyboard users; stacked Artifacts still nests scroll containers inside main overflow-auto inside page scroll. Fix: always-visible reduced-opacity gutter or tap-to-select line; list OR viewer below stack breakpoint with one scroll container.
- P2 NewTaskPage: unlabeled controls, "Save draft" primary while "Create" (launches an agent) is outlined, 3xl heading. Fix: two labeled rows (Where / How), primary "Create and start research questions", secondary "Save as draft".
