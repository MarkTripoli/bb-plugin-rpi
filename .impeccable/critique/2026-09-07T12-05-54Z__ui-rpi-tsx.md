## Design Specificity Verdict

**LLM assessment:** Strongly product-specific data model and terminology but visually reads as generic data-table-with-sidebar. Sidebar grouping and pill system show product character. Task detail feels like CRUD admin. "Needs You" band is strongest product-specific element.

**Deterministic scan:** Zero findings. Host token classes exclusively, proper component patterns, convention tests pass.

## Overall Impression

Moved from "functional prototype" to "works, has character in places." StatusPill tone system and collapsible sidebar are genuine improvements. Biggest opportunity: task detail tries to be everything at once (7 tabs, equal weight). "Inbox before tracker" works in sidebar/Needs You band but breaks in task detail.

## What's Working

1. StatusPill tone system with 5 tones and consistent pill/text/row-shade classes. "Needs human" as attention-yellow rather than alarm-red is correct.
2. Collapsible sidebar with smart defaults (expand active/needs-human, collapse rest, persist to localStorage, project grouping only when needed).
3. Needs You band as dedicated inbox surface.

## Priority Issues

**[P1] Seven-tab task detail overwhelms.** Sessions and Artifacts are primary; 5 secondary tabs (Workspace, Auto-advance, Tips, Scratch, Minimap) have equal weight. Fix: collapse to "More" overflow or move to thread-side panels.

**[P1] Error messages are developer jargon.** "stale extraction," "no_source_host," "missing_completed_turn" surfaced as toasts. Fix: map error codes to human sentences.

**[P2] No keyboard shortcut discoverability.** 52 hotkey references, zero visible hints. Fix: add hints to tooltips, add shortcuts panel.

**[P2] Inconsistent interaction patterns.** Sidebar rows have three-dot menu; task detail session rows have different actions; task rows have none. Fix: standardize row-action vocabulary.

**[P2] 4943-line monolith.** Every component in one file blocks design-system reuse and evolution. Fix: extract shared components.

## Persona Red Flags

**Alex (Power User):** No visible keyboard shortcuts. No bulk actions. Three-dot menu requires precise mouse targeting. No "dismiss all" on Needs You band.

**Sam (Accessibility):** Zero sr-only classes. Status communicated by color alone. Three-dot trigger needs aria-label. Collapse chevrons lack aria-expanded. SplitHandle has no keyboard resize. 51 aria attributes sparse for 53 buttons.
